title: proxer server

---

`proxer server`는 공개 트래픽, health probe, 터널 제어를 처리하는 HTTP/WebSocket 리스너 하나를 시작합니다.

## 사용법

```bash
proxer server --listen 0.0.0.0:8080 --domain your-server.example.com --token dev-token
```

## 옵션

- `--listen <host:port>`: 리슨 주소입니다. 기본값은 `127.0.0.1:8080`입니다.
- `--domain <domain>`: 루트 및 서브도메인 경로를 계산할 공개 루트 도메인입니다.
- `--token <token>`: 터널 클라이언트가 사용해야 하는 공유 토큰입니다.
- `--trusted-proxy <proxy>`: 신뢰할 reverse proxy preset, IP, CIDR입니다. 여러 값을 쓰려면 flag를 반복합니다.

`--token`과 `PROXER_TOKEN`을 모두 생략하면 서버는 강한 토큰을 생성하고 `token: ...` 형식으로 출력합니다. 그 값을 클라이언트에 복사하세요. 오래 운영하는 배포에서는 터미널 출력에 의존하기보다 secret 저장소를 쓰는 편이 낫습니다.

신뢰 프록시 preset:

- `loopback`: loopback 주소.
- `private`: 사설 IPv4 대역과 unique-local IPv6 대역.

`--trusted-proxy` 또는 `PROXER_TRUSTED_PROXIES`를 설정했다면 reverse proxy는 외부 클라이언트가 보낸 `X-Forwarded-*`와 `X-Real-IP` 헤더를 Proxer로 전달하기 전에 덮어쓰거나 제거해야 합니다.

## 환경변수

- `PROXER_LISTEN`: `--listen` 기본값.
- `PROXER_DOMAIN`: `--domain` 기본값.
- `PROXER_TOKEN`: `--token` 기본값.
- `PROXER_TRUSTED_PROXIES`: comma-separated 신뢰 프록시 값.

CLI flag가 환경변수보다 우선합니다.

## 내부 엔드포인트

서버는 다음 고정 경로를 예약합니다.

```text
/__proxer__/control
/__proxer__/health/live
/__proxer__/health/ready
```

제어 경로는 설정할 수 없습니다.

## 참고

공개 머신에서 직접 실행하거나 원래 `Host` 헤더를 보존하는 reverse proxy 뒤에서 실행하세요. 알 수 없는 호스트는 `404`를 반환합니다.
