---
title: proxer skill install
description: AI 에이전트를 위한 Proxer 스킬 파일을 설치합니다.
---

`proxer skill install <directory>`는 AI 에이전트가 Proxer 워크플로를 실행하거나 설명할 때 사용할 수 있는 재사용 가능한 스킬 파일을 작성합니다.

---

## 사용법

```bash
proxer skill install <directory>
```

명령은 다음 파일을 작성합니다.

```text
<directory>/proxer.md
```

---

## 옵션

- `--dry-run` — 디렉터리나 파일을 만들지 않고 대상 경로만 출력합니다.
- `--force` — 기존 `proxer.md` 파일을 덮어씁니다.

이 명령에는 환경변수가 없습니다.

---

## 예시

설치 위치를 미리 확인합니다.

```bash
proxer skill install ./skills --dry-run
```

스킬을 설치합니다.

```bash
proxer skill install ./skills
```

기존 스킬 파일을 갱신합니다.

```bash
proxer skill install ./skills --force
```

---

## 덮어쓰기 안전장치

`proxer.md`가 이미 있으면 `--force`를 전달하지 않는 한 명령은 실패합니다. 로컬 에이전트 지시문이 실수로 교체되는 것을 막기 위한 동작입니다.
