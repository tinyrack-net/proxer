title: proxer http

---

`proxer http <port>`는 공개 Proxer 서버에 연결하고, 일치하는 공개 요청을 클라이언트 머신의 `127.0.0.1:<port>`로 전달합니다.

## 사용법

```bash
proxer http 3000 --server wss://your-server.example.com --subdomain demo --token dev-token
```

## 옵션

- `<port>`: 전달할 로컬 HTTP 포트입니다. 이 positional 인자에는 환경변수가 없습니다.
- `--server <url>`: Proxer 서버 base URL입니다. `ws://`, `wss://`, `http://`, `https://`를 사용할 수 있고, HTTP scheme은 내부적으로 WebSocket scheme으로 바뀝니다. path, query, fragment는 넣지 마세요.
- `--subdomain <name>`: 서브도메인 경로를 등록합니다. 생략하면 루트 경로를 등록합니다.
- `--token <token>`: 서버와 일치해야 하는 공유 토큰입니다.

`--token` 또는 `PROXER_TOKEN`은 필수입니다. 없으면 `token is required` 오류로 종료됩니다.

## 환경변수

- `PROXER_SERVER`: `--server` 기본값.
- `PROXER_SUBDOMAIN`: `--subdomain` 기본값.
- `PROXER_TOKEN`: `--token` 기본값.

CLI flag가 환경변수보다 우선합니다.

## 경로

루트 경로:

```bash
proxer http 3000 --server wss://proxy.example.com --token dev-token
```

`proxy.example.com` 요청은 로컬 서비스로 전달됩니다.

서브도메인 경로:

```bash
proxer http 3000 --server wss://proxy.example.com --subdomain demo --token dev-token
```

`demo.proxy.example.com` 요청은 로컬 서비스로 전달됩니다.

서브도메인은 소문자로 정규화되며 단일 DNS label이어야 합니다. 영문 소문자, 숫자, 하이픈만 가능하고, 하이픈으로 시작하거나 끝날 수 없으며, 최대 63자입니다.

## 재연결

이미 연결된 제어 연결이 끊기면 클라이언트는 재시도하고 서버에 닿으면 다시 등록합니다. 초기 연결이 등록 전에 실패하면 명령이 종료될 수 있습니다.
