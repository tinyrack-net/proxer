---
title: Docker
description: 게시된 OCI 이미지로 Proxer를 실행합니다.
---

OCI 이미지는 Docker Hub의 `tinyrack/proxer`와 GHCR의 `ghcr.io/tinyrack-net/proxer`로 게시됩니다.

이미지 버전을 확인합니다.

```bash
docker run --rm tinyrack/proxer --version
```

Docker에서 공개 Proxer 서버를 실행하고 `8080` 포트를 게시합니다.

```bash
docker run --rm -p 8080:8080 tinyrack/proxer server --listen 0.0.0.0:8080 --domain your-server.example.com --token dev-token
```

Linux에서는 컨테이너가 Docker 호스트의 서비스에 접근해야 할 때 host networking으로 터널 클라이언트를 실행합니다.

```bash
docker run --rm --network host tinyrack/proxer http 3000 --server ws://127.0.0.1:8080 --subdomain demo --token dev-token
```

macOS 및 Windows Docker Desktop에서는 컨테이너가 호스트의 로컬 서비스에 접근해야 할 때 `127.0.0.1` 대신 `host.docker.internal`을 사용하세요.
