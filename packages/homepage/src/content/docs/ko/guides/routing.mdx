---
title: 라우팅과 신뢰 프록시
description: 루트 및 서브도메인 호스트를 라우팅하고 reverse proxy 뒤에서 배포합니다.
---

Proxer는 들어오는 호스트를 기준으로 공개 요청을 라우팅합니다.

- `--subdomain`이 없는 클라이언트는 설정된 루트 도메인을 등록합니다.
- `--subdomain demo`를 사용하는 클라이언트는 `demo.<domain>`을 등록합니다.
- 알 수 없는 서브도메인은 `404`를 반환합니다.

Proxer가 Traefik 또는 다른 reverse proxy 뒤에서 실행될 때는 `X-Forwarded-*` 헤더를 제공할 수 있는 TCP peer 주소를 설정해야 합니다. 신뢰 프록시가 없으면 Proxer는 라우팅을 위해 전달된 host, protocol, client IP 헤더를 무시합니다.

```bash
PROXER_LISTEN=0.0.0.0:8080 \
PROXER_DOMAIN=proxy.intranet.example.com \
PROXER_TRUSTED_PROXIES=private,loopback \
PROXER_TOKEN=... \
proxer server
```

프록시를 통한 클라이언트 설정 예시입니다.

```bash
PROXER_SERVER=wss://proxy.intranet.example.com \
PROXER_CONTROL_PATH=/__proxer_control_7f3d9a2b__ \
PROXER_SUBDOMAIN=demo \
PROXER_TOKEN=... \
proxer http 3000
```

지원되는 신뢰 프록시 값은 `loopback`, `private`, IP 리터럴, CIDR 범위입니다. 직접 제어하는 reverse proxy만 신뢰하세요.
