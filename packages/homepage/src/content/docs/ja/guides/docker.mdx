---
title: Docker
description: 公開済みOCIイメージでProxerを実行します。
---

OCIイメージはDocker Hubの`tinyrack/proxer`とGHCRの`ghcr.io/tinyrack-net/proxer`で公開されています。

イメージのバージョンを確認します。

```bash
docker run --rm tinyrack/proxer --version
```

Dockerで公開Proxerサーバーを実行し、`8080`ポートを公開します。

```bash
docker run --rm -p 8080:8080 tinyrack/proxer server --listen 0.0.0.0:8080 --domain your-server.example.com --token dev-token
```

Linuxでは、コンテナがDockerホスト上のサービスへ到達する必要がある場合、host networkingでトンネルクライアントを実行します。

```bash
docker run --rm --network host tinyrack/proxer http 3000 --server ws://127.0.0.1:8080 --subdomain demo --token dev-token
```

macOSおよびWindows Docker Desktopでは、コンテナがホスト上のローカルサービスへ到達する必要がある場合、`127.0.0.1`ではなく`host.docker.internal`を使ってください。
