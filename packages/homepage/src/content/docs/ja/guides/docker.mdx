OCIイメージはDocker Hubの`tinyrack/proxer`とGHCRの`ghcr.io/tinyrack-net/proxer`で公開されています。

イメージのバージョンを確認します。

```bash
docker run --rm tinyrack/proxer --version
```

---

## サーバーを実行する

```bash
docker run --rm -p 8080:8080 tinyrack/proxer \
  server \
  --listen 0.0.0.0:8080 \
  --domain proxy.example.com \
  --token dev-token
```

サーバーにボリュームは不要です。トンネル登録はメモリ上にあり、クライアントが再接続すると再作成されます。

---

## Docker Compose

```yaml
services:
  proxer:
    image: ghcr.io/tinyrack-net/proxer:latest
    command:
      - server
      - --listen
      - 0.0.0.0:8080
      - --domain
      - proxy.example.com
    environment:
      PROXER_TOKEN: dev-token
      PROXER_TRUSTED_PROXIES: loopback,private
    ports:
      - "8080:8080"
    healthcheck:
      test: ["CMD", "proxer", "--version"]
      interval: 30s
      timeout: 5s
      retries: 3
```

## Kubernetesヘルスチェック

プラットフォームがHTTPパスをprobeできる場合は、固定のヘルスエンドポイントを使います。

```text
/__proxer__/health/live
/__proxer__/health/ready
```

制御エンドポイントも固定です。

```text
/__proxer__/control
```

## 環境変数

サーバーは`PROXER_`環境変数で設定できます。

```bash
docker run --rm -p 8080:8080 \
  -e PROXER_DOMAIN=proxy.example.com \
  -e PROXER_TOKEN=dev-token \
  -e PROXER_TRUSTED_PROXIES=loopback,private \
  ghcr.io/tinyrack-net/proxer server
```

コンテナが管理下のreverse proxyからトラフィックを受ける場合は、`--trusted-proxy`または`PROXER_TRUSTED_PROXIES`を設定してください。
