# Proxer

**Reverse-tunnel CLI skeleton for Tinyrack.**

[![Node.js](https://img.shields.io/badge/node-%3E%3D24-brightgreen)](https://nodejs.org/)

</div>

---

Proxer is a Node.js CLI project for reverse-tunnel workflows. The current repository state is intentionally limited to the monorepo, TypeScript, Vitest, and Biome skeleton.

## Development

```bash
pnpm install
pnpm run build
pnpm run typecheck
pnpm run test
pnpm run format:check
```

## CLI

```bash
pnpm --filter @tinyrack/proxer start
```
